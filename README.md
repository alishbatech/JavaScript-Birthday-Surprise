# 🎂 Birthday Surprise Website

A fun and interactive Birthday Surprise Website built with HTML, CSS, and JavaScript.
I created this project to practice JavaScript DOM manipulation, event handling, animations, dynamic elements, and interactive UI.

The website takes the user through multiple screens with different birthday surprises, animations, and effects. 🎁✨

## ✨ Features

### 🎬 Multi-Screen Navigation
  
  - Smoothly move through different birthday surprise screens.
  - Screens are shown/hidden dynamically using JavaScript.

### 🎁 Interactive Gift Reveal
  
  - Animated gift opening effect.
  - Dynamically created gift lid and shine effects.
  - Spark particles appear when the gift is opened.

### 💌 Animated Birthday Letter
  
  - Birthday message appears with a typing effect.
  - Text is displayed character by character using JavaScript.

### 🎂 Candle Blow Effect
  
  - Interactive cake animation.
  - Candles disappear after the button is clicked.
  - Cake changes to a celebration state.

### 🎉 Confetti Celebration
  
  - Dynamically generated confetti pieces.
  - Random positions, sizes, shapes, and colors.
  - Falling animation using CSS keyframes.

### ⌨️ Keyboard Shortcuts
  
  - Press "N" to trigger the next visible button.
  - Press "R" to reload the page.

### 🔄 Replay-Friendly
  
  - Different animations and elements are reset when moving between screens.

## 🛠️ Technologies Used

- HTML5 — Structure of the website
- CSS3 — Styling, transitions, and animations
- JavaScript (Vanilla JS) — Interactions, DOM manipulation, events, dynamic elements, and animations
